How a job runs

Every project, the same auditable sequence.

Whatever the location or operator, an IWS scope follows the same controlled, documented path — so the record you receive looks identical from the first onshore well to the most remote offshore platform.

Prequalify & plan

We confirm material grades, sour-service requirements and the approved welding procedure before any crew mobilises, so the job is engineered before it starts.

Install & weld

Wellhead and casing-head installation with chart-recorded preheat and inter-pass temperatures, producing crack-free welds that meet ASME, API and ISO requirements.

Test & hand over

Gas testing begins sooner thanks to localized heating, and every weld is handed over with a preheat chart and PWHT record the operator can audit.
